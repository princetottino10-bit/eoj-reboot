# 箱絵 ブリーフ (11/05)

前回(11/01)の反省: 手引きの順番(ブリーフ → 理由の表 → 白黒の構図案 → 比率ごとの切り抜き)を飛ばして、いきなり生成した。
1枚に「9マス・置く場所・向き・主・式神2体・左上の空き」を全部入れたので、焦点がなく、ルール説明図のような絵になった。

## ブリーフ

| 項目 | 決めたこと |
|---|---|
| 誰に | ボードゲーム好き。まだこの作品を知らない人 |
| どこで | CFページの一番上、箱の表(A5横 10:7)、SNSのサムネ |
| 何秒 | 2〜3秒(一覧で流し見されるとき) |
| 行動1つ | 指を止めて、ページを開く |
| 感情1つ | 「この一枚で盤がひっくり返る」という一手の緊張 |
| 作品にしか言えないこと | 3×3 の九宮盤の、どのマスに・どの向きで式神を喚ぶかで勝負が決まる |

## 理由の表(正本 → 形)

| 正本にあること | 絵での形 |
|---|---|
| 九宮盤は3×3、中央に太極のマス | 盤の中央マスを一番明るくする(1位)。太極の模様を光で描く |
| 札を置いて式神を喚ぶ | 札を叩きつける手と、札から立ち上がる式神 |
| 向きと間合で攻める | 式神の視線と、光る隣のマスの並びで「向き」を見せる。矢印や図は描かない |
| 2人対戦 | 陽(青緑)と陰(朱)の2色だけ。各陣営の式神を1体ずつ |
| 玖龍街(舞台) | 背景は暗く落として、看板の光だけにする |

表に無い要素は外す: 遠くの塔、群衆、多すぎる式神、文字のある看板。

## 順位(明暗差)

1. 中央の太極マスと、そこへ置かれる札(一番明るく、一番色が強い)
2. 立ち上がる式神の顔(視線は相手へ)
3. 相手の式神、主(暗く、粗くてよい)

## 使う大きさ

- 箱の表 10:7(A5横)… 主
- CF の一番上 16:9、Kickstarter のサムネ 1024×576
- SNS 1:1、縦 9:16
- 題字は左上に置く前提で、そこには顔や手を置かない
