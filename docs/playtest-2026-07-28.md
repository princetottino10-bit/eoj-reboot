## 2. パス時の手札入れ替え(新ルール)

> 召喚をパスするとき、手札を1枚捨ててよい。

`spell-candidates.md` §1 の前提「手札はコストにならない。捨てる行為は翌ターンに埋まるうえ、デッキが回ってカードの質が上がるため、**コストではなく利益になりうる**」と正面から関係する。**このルールは意図的に「利益」の側に振ったもの**と読める。

決めるべきこと:

- [ ] 捨てるのは**任意**か、パスしたら**必ず**か
- [ ] 墓地へ送るのか、デッキボトムか(墓地リシャッフルがあるので実質差は小さい)
- [ ] 1枚上限でよいか
- [ ] **霊力を貯める手(パス)に、さらに手札の質を上げる利益を足してよいか。** 「先手の初手パスが有利になる」問題(2026-07-08 に議論、初手召喚の義務化が対策案として挙がっていた)を悪化させる方向に働く

## 4. 術式の枚数(16+4 か 16+8 か)

| 構成 | 所感 |
|---|---|
| 16 + 4(20枚) | 「やや物足りない」「1試合で1〜2回使えてちょうどよい」で**割れた** |
| 16 + 8(24枚) | 「多い」「ちょうどよい」で**割れた**。3ターン目に**手札5枚中5枚が術式**になる事故が発生 |

### 論点

**盤面を取り合うゲームなので、術式は盤面の味を引き立てる側であるべき**という見方が出ている。術式が主役なら盤面は要らない、という筋。

一方で `spell-candidates.md` §1 の密度計算は 4/20 = 20%(初期手札に1枚以上入る確率71.8%、期待1.00枚)で組んである。8/24 = 33% は**期待1.67枚**で、手札の1/3が召喚できないカードになる。3ターン目に全部術式という事故は、確率的に十分起こりうる範囲。

### 出ている案

- **一門(派閥)ごとに術式の枚数を変える。** 術式が多い一門を1つ作り、他は少なくする。「アイテムをガンガン使いたい人」に応えつつ、盤面主体の性格を壊さない
- **術式だけデッキ構築させる**(式神は固定、術式のみ選択制)。未検討

### 決めるべきこと

- [ ] 20枚(16+4)か24枚(16+8)か、あるいは一門ごとに可変か
- [ ] 開発内に「多い」と感じた人がいる時点で、プレイヤー側にも同じ割合で必ずいる。**枚数を増やす方向は、術式1枚あたりの質が上がってから**判断するのが安全

## 6. 次にやること

この回の最大の収穫は、**術式より先に式神の所持効果を設計すべき**という結論が出たこと。

> 式神に効果がない状態では、術式側のバランスの取り方を決めようがない。術式(霊具)は0枚でもゲームとして成立するので、**式神効果で解決しない問題が具体化してから**術式を設計するほうが確実。

設計は [`effect-rank-design.md`](effect-rank-design.md) へ。
