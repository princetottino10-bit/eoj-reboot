## 以下は中止前の元の依頼内容(記録として残す)

## 1. 何を知りたいか

RULE_SPEC §9.2 の召喚位置制限——「自分の式神が盤面に1体でもあれば、**いずれかの式神(敵味方問わず)と上下左右に隣接する空きマス**にしか召喚できない」——を**撤廃**したとき、ゲームがどう変わるかを測る。

判断したいのは次の2点。

1. **このルールは実際に拘束しているのか。** 3x3の9マスで「敵味方問わず隣接」という条件は、盤面に数体あればほぼ全マスを合法にしてしまう可能性がある。もし合法手集合がほとんど変わらないなら、**ルールを1つ減らして説明コストを下げられる**。
2. **拘束しているなら、何を守っているのか。** 撤廃で制圧勝ちが増え試合が短くなるなら、この制限は「5マス制圧レースの速度制御」として機能している。先手勝率が動くなら先後バランスにも効いている。

## 2. 変更箇所(実質3行)

`engine/src/targeting.ts:132`

```ts
/** 9.2 召喚位置の制限。 */
export function legalSummonPositions(ctx: MatchContext, state: MatchState, player: PlayerId): Pos[] {
  const size = ctx.constants.BOARD_SIZE;
  const hasOwn = state.units.some((u) => u.owner === player);
  const out: Pos[] = [];
  for (let x = 0; x < size; x++) {
    for (let y = 0; y < size; y++) {
      const p = { x, y };
      if (unitAt(state, p)) continue;
      if (!hasOwn) out.push(p);
      else if (state.units.some((u) => isAdjacent(u.pos, p))) out.push(p);   // ← この行を削除
      out.push(p);                                                           // ← 空きマスは無条件に合法
    }
  }
  return out;
}
```

条件Bでは `hasOwn` / `isAdjacent` の判定を外し、**空きマスをすべて合法**にする。他の箇所には触らない。

エンジン側のテスト(`engine/test/rules.test.ts` 他)に隣接制限を前提としたケースがあれば、**条件Bのブランチでのみ** skip または期待値変更してよい。テストを恒久的に壊さないこと。

## 5. 交絡要因(必ずレポートに書くこと)

**分岐数が増える。** 隣接制限を外すと1手あたりの召喚候補が増える(最大で空きマス数×向き4)。Lv6/Lv7は**5,000ノードの予算内で反復深化**するため、**同じ予算でも実質的な探索深度が浅くなる**。

つまり条件Bの結果は「ルール変更の効果」と「AIが相対的に弱くなった効果」の合成である。この解釈を明記したうえで、次のどちらかで扱う:

- **既定**: ノード予算5,000を固定したまま比較し、「**同じ計算資源を与えたときの差**」として報告する。人間のプレイヤーも思考資源は有限なので、これはこれで意味のある比較
- **余力があれば条件C**: Bと同じルールでノード予算を増やす(例: 15,000)。500試合でよい。BとCの差が小さければ「探索劣化は主因ではない」と言え、Bの結果をルール変更の効果として読める

条件Cまで回せるかは実行時間次第。**Bまでで報告してよい**(Cは任意)。

## 6. 取得するKPI

A・Bを2列で並べ、差(pt / 絶対値)も出す。

| 指標 | 見たい理由 |
|---|---|
| **先手勝率** | 撤廃が先後バランスを壊さないか。基準帯は45〜55% |
| **撃破勝ち / 制圧勝ち の比率** | 撤廃で制圧レースが加速するか |
| **平均ターン / 中央値 / P90** | 試合が短くなるか |
| **死角率** | 相手の背後に直接召喚できるようになる影響 |
| **反撃率** | 同上の裏返し |
| **王手発生数 / 制圧転換率 / 先手王手勝率** | 王手の攻防が壊れないか |
| **合法召喚位置の平均数(A/B両方)** | **最重要**。§1の問い1に直接答える。ターンごとの合法召喚マス数を記録し、A・Bの平均と分布を出す |

**最後の項目を必ず取ること。** AとBで合法手数がほとんど変わらないなら、他のKPIが動かないのは当然であり、「このルールは拘束していない」という結論が直接得られる。逆に大きく違うのに他のKPIが動かないなら、「自由度は増えるが勝ち方は変わらない」という別の結論になる。

## 7. 事前登録した予想(答え合わせ用)

**差は小さいと予想する。**

理由: 現行ルールの隣接判定は `state.units.some(...)` で**敵味方を問わない**。3x3の9マスでは、盤面に3〜4体あれば空きマスのほとんどが誰かに隣接する。制限が実際に効くのは**序盤の2〜3手目**と、自駒が盤の端に固まった局面くらいのはず。

したがって:

- 合法召喚位置の平均数: A と B の差は**1マス未満**と予想
- 先手勝率・撃破/制圧比・平均ターン: **有意差なし**(2000試合の誤差±2.2pt以内)と予想
- 死角率: わずかに上昇(序盤に相手の背後を直接取れるため)

**この予想が当たった場合、それは「ルールを消してよい」という提案になる。** ルールが1つ減れば説明コストが下がり、初見プレイヤーのつまずき(7/18テストで「召喚の隣接制限」は説明つまずきポイントとして挙がっていた)も1つ消える。

**予想が外れて差が大きかった場合**は、この制限が速度制御として機能していたことになり、撤廃するなら別の減速装置が要る——という結論になる。どちらに転んでも情報が得られる設計になっている。
