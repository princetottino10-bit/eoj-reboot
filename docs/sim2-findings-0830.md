# 新ルール(8/28改訂第1弾)シミュレーション所見 — 9/5テスト前の共有用

Date: 2026-08-30
方法: 新ルールを実装した自己対戦シミュレータ(sim2)で、**付喪神+京鬼デッキのミラーマッチ**をAI同士に対戦させた。カード効果・霊具あり/なしの両方で測定。計約900試合。
再現: `sim2/` 参照(設計 `DESIGN.md`、結果 `RESULTS-SMOKE.md` / `RESULTS-EVAL.md` / `RESULTS-EFFECTS.md`)

---

## 結論(3行)

1. **改訂は狙いどおり効いている。** 制圧決着がほぼ100%になり、8/23の「制圧が一度も起きない」は解消
2. **ただし効きすぎの兆候。** 平均5.7〜6.6ラウンド(目標8〜10より短い)、先手勝率61〜82%、占拠差の裏返り(逆転)0件 — 事前登録した危険信号「先に埋めた側が勝つレース」が点灯
3. **カード効果と霊具が最大の緩和装置だった。** 効果を入れるだけで先手勝率が9〜12pt下がり、撃破6倍・リーチ返し2倍。**残る先手有利はルールでなくカード設計で詰められる可能性が高い**

### 補足の実測

- **チップの点火は速い**: 3枚目(収入+1)は平均R2.7〜3.0、4枚目はR3.6〜4.0。ただし試合が6R強で終わるため、**収入ブーストが効く期間は2ターン程度**
- **AIの方策(陣取り重視/攻撃重視/バランス)を入れ替えても勝敗は1試合も変わらなかった**(100シード中100で同一勝者)。決着の型はプレイヤーの好みではなく**トラックの速度差**で決まっている: 制圧は約6Rで完走、生命15を生命価で削り切るには10R以上かかる
- **霊具の使用内訳(100試合)**: マヨヒガ119 / 家鳴り82 / 閻魔獄卒棒70 / 鬼の酒63 / 琵琶牧々23。**マヨヒガ(対象をカウントから除外)がリーチ返しの主手段**としてAIに最多使用された

## 3. 注意書き(数値の限界)

- AIの読みは浅い(1〜2手)。**人間はもっと攻撃し、もっとミスをする**ため、実測はシミュより穏やかに出るはず
- 効果実装は付喪神+京鬼のみ。**九尾+龍デッキの霊具6枚は未実装**
- 手札交換はAIでは固定則(人間の駆け引きは未反映)
- 個々の数値より**方向と順位**(何が大きく、何が小さいか)を信じること

## 4. もし危険信号が人間テストでも出た場合の調整候補(参考)

シミュから見える序列:

1. **カード側の干渉手段を増やす**(最も効いた実証あり: 効果導入だけで先手−9〜12pt)
2. リーチ保持を2ターンにする(予備案タブの「4マス+1ターン保持」と同系の速度ノブ)
3. 収入・チップ段の調整(試合が6Rで終わる限りチップ経済は活きない)

生命決着は効果込みでもほぼ発生しないため、**生命価の廃止判断の材料**にもなる(測定タブの「生命価勝ちが0なら次の調整で外す判断材料」に該当する結果が出ている)。
