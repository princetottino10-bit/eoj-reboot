## 第1段の結論(引き継ぎ)

## 第2段の方針

v4骨格(撃破時霊力2 / 死角+1 / C2:HP2・C3:HP2・C4:HP5 / 陰陽+太極 / 紙配置)は引き続き固定。**ATKカーブ**(v4骨格に含まれない)で撃破の源流を抑える。

期待メカニズム: ATK減 → 撃破減 → ①生命出血減(源流)②盤面が保ち占拠決着が早まる=試合短縮(Lと逆)③王手返し率低下。
