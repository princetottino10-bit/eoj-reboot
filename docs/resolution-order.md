## 1. マスの番号と記法(確定)

盤の9マスに、**左上から右下へ 1〜9** を振る。

```
 1  2  3          空   陰   空
 4  5  6    =     陰  太極  陽
 7  8  9          空   陽   空
```

番号は**マスに固定**する。駒ではないので、召喚・撃破・移動が起きても番号は変わらない。

### 1.1 覚え方(設計上の副産物)

| | |
|---|---|
| **偶数マス(2・4・6・8)** | すべて属性マス(陰・陽) |
| **奇数マス(1・3・5・7・9)** | すべて空マス。うち5が太極 |

**太極が5**になるのは、風水の**九宮(洛書)**の魔方陣の中央が5であることと一致する。盤面に数字を刷ることが、世界観の側からも自然に説明できる。

### 1.2 盤の向きは固定する(重要)

**対面2人プレイなので「左上」はプレイヤーごとに異なる。** 片方から見た1は、もう片方から見れば9になる。

- **番号は盤面に印刷し、両者が同じ向きで読む**こと
- デジタル版も同じ絶対番号を使うこと。プレイヤーごとに回転させない

### 1.3 攻撃範囲の座標とは別物

正本の攻撃範囲は `[-1,1]` `[0,1]` のような**相対座標**で、第2成分が前後(+1が前方)、第1成分が左右。これは**式神の向きに依存する**。

一方このマス番号は**盤に固定された絶対座標**。両方が必要で、混同しないこと。

- マス番号 n → 行 = `⌈n/3⌉`、列 = `((n−1) mod 3) + 1`

### 1.4 攻撃範囲・死角の記法(2026-07-29 確定)

**向きを上に固定し、周囲のマスに盤と同じ読み順で番号を振る。** 盤面の 1〜9(§1)と同じ「左上から」なので、覚える規則は1つで足りる。

```
    0        ← 前2(直線2マス先。ここだけ距離2)
 1  2  3
 4  ●  6     ● = その式神自身
 7  8  9
```

書式は **`範囲 / 死角`**。範囲・死角とも、該当するマス番号を昇順で並べる。

| | |
|---|---|
| `2/8` | 前1が範囲、後1が死角 |
| `123/8` | 前3マスが範囲、後1が死角 |
| `02/46` | 前1と前2が範囲、左右が死角 |

#### 対象数は「全」の1文字だけ

**無印 = 範囲内から1体を選ぶ。`全` = 範囲内の全てを攻撃(敵味方問わず・強制)。**

```
2/8        単体（1マスなので選ぶ余地がない）
123/8      範囲から選択（3マスのうち1体）
123全/8    範囲全体（3マス全部・味方も巻き込む）
```

**`単` は書かない。範囲が1桁なら選択の余地がなく、記法から自明だから。** 印が付くのは「味方も巻き込む」という事故る側だけ ── **驚くほうのルールにだけ印が付く**形にしてある。逆にすると無印カードを見るたびに全体かどうかの確認が要る。

将来「範囲内から2体まで」が必要になったら `123:2/8` のように数字を足して拡張できる。現時点では不要。

#### 素体と並べて1行で書く

```
薙刀霊   4/5/2 · 123/8
九尾     6/7/3 · 12346/8
龍       7/8/4 · 0246/8
```

前半が `召喚霊力/HP/ATK`、後半が `範囲/死角`。

#### この記法から形状予算が直読みできる

[`effect-rank-design.md`](effect-rank-design.md) §7 の形状係数は、記法の見た目からそのまま出る。

| 記法の特徴 | 形状予算 |
|---|---|
| **範囲の桁数** | マス数。加点段(3桁 = 3マス = +1.5) |
| **`0` を含むか** | 非隣接ボーナス +1.0 の有無 |
| **死角の桁数** | 減点(2桁 = −1.5) |

`0246` を見た瞬間に「4マス + 非隣接 = +3.0」と出る。検算表を引く必要がない。

## 2. 基本原則(確定)

> **同時に複数の処理が発生する場合、マス番号の若い順に処理する。**

多対象攻撃だけでなく、盤面上の複数の駒・マスに同時に働く効果すべてに適用する(術式「大地の怒り」など)。

---

## 3. 多対象攻撃の解決手順(確定・一括解決)

RULE_SPEC §10 の単体攻撃の順序 `攻撃宣言 → 補正 → ダメージ計算 → 撃破判定 → 反撃 → 最終撃破判定` を、**構造を保ったまま**多対象へ拡張する。

```
1. 攻撃宣言 ── 対象をすべて決定する
2. 補正 ──── 対象ごとに死角を個別判定            (若い順)
3. ダメージ ── 全対象に同時に適用
4. 撃破判定 ── 全対象をまとめて判定
5. 反撃 ──── 生き残った対象のうち、
              反撃範囲に攻撃側がいるものが反撃    (若い順)
6. 最終撃破判定 ── 攻撃側
```

### 3.1 逐次解決を採らない理由

対象1を殴る → 反撃 → 対象2を殴る → 反撃、という順にすると:

- 撃破判定と反撃が交互に来て、**§10 の順序構造が壊れる**
- 1体目の反撃で攻撃側が撃破されると、**2体目への攻撃が消える**
- 卓上で盤面を何度も行き来する

一括なら「撃破された相手は反撃しない」という既存ルールが全対象に同じく効き、処理も1往復で済む。

### 3.2 帰結 — 2体とも落とせば反撃はゼロ

一括解決では、ダメージ適用が撃破判定より先なので、**両方を撃破できれば反撃を1回も受けない**。逐次解決に比べて攻撃側に有利。これは対象数の値付けに直接効く(§5)。

## 4. 死角は対象ごとに個別判定(確定)

1回の攻撃の中で、**ある対象は死角から(ATK+2・反撃なし)、別の対象は正面から(反撃あり)**、という状態が普通に発生する。これを認める。

> **補正は死角だけ。属性は攻撃補正ではない。** 属性は `ATTRIBUTE_HP_BONUS=2`(属性マスに乗っている式神のHP+2)であって、攻撃時に乗る値ではない。RULE_SPEC §10 の補正ステップからは 2026-07-04 に削除済み。

### 帰結

1. **「片方だけ死角を取る」置き方が最適解になる。** 2体とも死角を取れる配置(相手2体が同時に背中を向けている)は稀なので、実戦では常に「どちらを死角から殴るか」の選択になる。**向きの読み合いが濃くなる方向**で、ゲームの核心に効く
2. **反撃も個別。** 同じ1回の攻撃で、反撃する対象としない対象が混ざる。**卓で必ず質問が出るので、ルールブックに明記すること**
3. **上限は ATK+2 が2体分。** ATK2の駒が両方死角なら 4+4=8ダメージで、C4(HP5)を2体まとめて落とせる。発生は稀だが上限として認識しておく

## 5. 対象数の値付けへの影響

詳細は [`effect-rank-design.md`](effect-rank-design.md) §6。

**結論だけ**: 一括解決(§3.2)は対象数を強くする方向に働くが、**対象は「範囲内全体を強制」で確定した**(2026-07-29)ため、盤面が埋まるほど自分の駒を巻き込んで撃てなくなる。勝ちに近づくほど使えなくなるので、差し引き **効果ランク2前後**。

『対象数』のカード表記は `単体`(範囲1マス) / `範囲から選択`(範囲複数マスから1体) / `範囲全体`(強制・FFあり) の3つだが、**前2つは同じルールなので、値付けの軸としては 選択 / 全体 の2値**(ランク 0 / 1・仮)。

本書 §3〜§4 の一括解決と死角の個別判定は3表記すべてに適用し、**§6.6 の味方関連の裁定は `範囲全体` にのみ適用する**。
