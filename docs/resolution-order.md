# 盤面の処理順序と多対象攻撃の裁定

Status: 確定(§6 のみ未決)
Date: 2026-07-29
関連: [`effect-rank-design.md`](effect-rank-design.md) §6 / `current-spec-ver1.md` §2

## 1. マスの番号(確定)

盤の9マスに、**左上から右下へ 1〜9** を振る。

```
 1  2  3          空   陰   空
 4  5  6    =     陰  太極  陽
 7  8  9          空   陽   空
```

番号は**マスに固定**する。駒ではないので、召喚・撃破・移動が起きても番号は変わらない。

### 1.1 覚え方(設計上の副産物)

| | |
|---|---|
| **偶数マス(2・4・6・8)** | すべて属性マス(陰・陽) |
| **奇数マス(1・3・5・7・9)** | すべて空マス。うち5が太極 |

**太極が5**になるのは、風水の**九宮(洛書)**の魔方陣の中央が5であることと一致する。盤面に数字を刷ることが、世界観の側からも自然に説明できる。

### 1.2 盤の向きは固定する(重要)

**対面2人プレイなので「左上」はプレイヤーごとに異なる。** 片方から見た1は、もう片方から見れば9になる。

- **番号は盤面に印刷し、両者が同じ向きで読む**こと
- デジタル版も同じ絶対番号を使うこと。プレイヤーごとに回転させない

### 1.3 攻撃範囲の座標とは別物

正本の攻撃範囲は `[-1,1]` `[0,1]` のような**相対座標**で、第2成分が前後(+1が前方)、第1成分が左右。これは**式神の向きに依存する**。

一方このマス番号は**盤に固定された絶対座標**。両方が必要で、混同しないこと。

- マス番号 n → 行 = `⌈n/3⌉`、列 = `((n−1) mod 3) + 1`

## 2. 基本原則(確定)

> **同時に複数の処理が発生する場合、マス番号の若い順に処理する。**

多対象攻撃だけでなく、盤面上の複数の駒・マスに同時に働く効果すべてに適用する(術式「大地の怒り」など)。

---

## 3. 多対象攻撃の解決手順(確定・一括解決)

RULE_SPEC §10 の単体攻撃の順序 `攻撃宣言 → 補正 → ダメージ計算 → 撃破判定 → 反撃 → 最終撃破判定` を、**構造を保ったまま**多対象へ拡張する。

```
1. 攻撃宣言 ── 対象をすべて決定する
2. 補正 ──── 対象ごとに死角・属性を個別判定      (若い順)
3. ダメージ ── 全対象に同時に適用
4. 撃破判定 ── 全対象をまとめて判定
5. 反撃 ──── 生き残った対象のうち、
              反撃範囲に攻撃側がいるものが反撃    (若い順)
6. 最終撃破判定 ── 攻撃側
```

### 3.1 逐次解決を採らない理由

対象1を殴る → 反撃 → 対象2を殴る → 反撃、という順にすると:

- 撃破判定と反撃が交互に来て、**§10 の順序構造が壊れる**
- 1体目の反撃で攻撃側が撃破されると、**2体目への攻撃が消える**
- 卓上で盤面を何度も行き来する

一括なら「撃破された相手は反撃しない」という既存ルールが全対象に同じく効き、処理も1往復で済む。

### 3.2 帰結 — 2体とも落とせば反撃はゼロ

一括解決では、ダメージ適用が撃破判定より先なので、**両方を撃破できれば反撃を1回も受けない**。逐次解決に比べて攻撃側に有利。これは対象数の値付けに直接効く(§5)。

## 4. 死角は対象ごとに個別判定(確定)

1回の攻撃の中で、**ある対象は死角から(ATK+2・反撃なし)、別の対象は正面から(反撃あり)**、という状態が普通に発生する。これを認める。

### 帰結

1. **「片方だけ死角を取る」置き方が最適解になる。** 2体とも死角を取れる配置(相手2体が同時に背中を向けている)は稀なので、実戦では常に「どちらを死角から殴るか」の選択になる。**向きの読み合いが濃くなる方向**で、ゲームの核心に効く
2. **反撃も個別。** 同じ1回の攻撃で、反撃する対象としない対象が混ざる。**卓で必ず質問が出るので、ルールブックに明記すること**
3. **上限は ATK+2 が2体分。** ATK2の駒が両方死角なら 4+4=8ダメージで、C4(HP5)を2体まとめて落とせる。発生は稀だが上限として認識しておく

---

## 5. 対象数の値付けへの影響

一括解決(§3.2)により、対象数は逐次解決より強い。詳細は [`effect-rank-design.md`](effect-rank-design.md) §6。

**結論だけ**: 素のダメージ換算ではランク1相当だが、盤面(占拠を2マス同時に減らす・撃破時霊力が2回入る)で見るとランク3以上。**一括解決を採ったので、ランク3寄りに読む。**

## 6. 未決事項

### 6.1 術式「相打ち」の扱い(保留)

`jutsushiki-deck-patterns.md` の「相打ち」(互いの射程内にいる敵2体に互いを攻撃させる)は、§2 の若い順を素直に適用すると、番号の小さい側が先に攻撃し、**相手を倒したらもう片方は攻撃できない**。「相打ち」という名前に対して片方だけ死ぬケースが多発する。

§3 の一括解決(ダメージ同時適用)を適用すれば名前と挙動が揃うが、**このカード自体の採否がまだ決まっていない**ため保留。採用を決める段階で合わせて裁定する。
