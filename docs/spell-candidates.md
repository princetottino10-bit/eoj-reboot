# スペル候補プール(20枚デッキ・スペル4枠)

Status: 検討中
Date: 2026-07-26
対象: 現行16枚(vanilla-4)に4枚の術式を加えて20枚にする案

---

## 0. 再行動ルールの改定(2026-07-26)

**回転攻撃を廃止し、回転と攻撃を分解して個別に値付けした。**

| 行動 | コスト | 制限 |
|---|---:|---|
| 回転 | **1**(一律・コスト帯によらない) | 1ターン1回 = **90度まで** |
| 攻撃 | 2/2/2/3/3/3(コスト帯依存) | 1ターン1回 |
| 順序 | **回転 → 攻撃 のみ** | 攻撃したらその式神の再命令は終了。攻撃後の回転は不可 |

価格の変化:

| | 旧 | 新 | 差 |
|---|---:|---:|:-:|
| 回転のみ(C2〜C4) | 2 | **1** | −1 |
| 回転のみ(C5〜C7) | 3 | **1** | **−2** |
| 攻撃のみ | 2〜3 | 2〜3 | 据え置き |
| 回して殴る | 2〜3(回転攻撃) | 3〜4 | **+1** |

**重要な帰結: 盤上の式神は1ターンに180度回れない**(召喚時のみ向き自由)。これが旋の存在価値を決めている。

**この改定により、既存のベースラインはすべて無効。** 先手57.5%、王手8.54回/制圧転換0.84回、死角率16.5%はいずれも旧行動経済の測定値であり、参照点として使えない。

## 1. 前提

### コスト通貨は霊力のみ

手札はコストにならない。RULE_SPEC §6.5 により毎ターン `MAX_HAND`(5枚)まで補充され、デッキが尽きても墓地をシャッフルして継続する(§15)。手札を捨てる行為は翌ターンに埋まるうえ、デッキが回ってカードの質が上がるため、コストではなく利益になりうる。

EOJで手札コストが機能しているのは、あちらに自動補充がないため。**この仕組みは輸入できない。**

召喚枠(スペルを撃つと召喚不可)も候補だが、0/1のバイナリで調整ノブを持てない。霊力なら1〜3で連続的に掃引できる。

### 追加ルール(1行)

> スペルはメインフェイズ中、召喚より前に、1ターン1枚まで使用できる。霊力を消費するが、召喚枠は消費しない。

霊力収入は3/ターン。コスト2のスペルを撃つとC2式神しか召喚できず、コスト3なら召喚できない。**放置しても召喚と競合する。** 1ターン1枚の上限は、霊力上限15まで貯めての連打を防ぐ保険。

### 密度

4/20 = 20%(EOJの比率と一致)。

- 初期手札5枚に1枚以上入る確率: **71.8%**
- 手札5枚あたりの期待枚数: **1.00枚**

召喚可能なカードは平均5枚→4枚に減るが、召喚は1ターン1回なので実害は小さい。

## 2. 採用基準

### 基準1: 能動性 — 撃った瞬間に何かが起きるか

「相手がこう来たら効く」カードは、撃った瞬間に盤面が動かず、読みを外したとき何も残らない。

**判定は"条件"ではなく"効果"で行う。** 窮鼠は発動条件が受動的(相手が4マス占拠)だが、効果は能動的(自分の駒が盤面を飛ぶ)なので合格。

**文脈で裏返る効果に注意。** HP+3は、何も起きていない盤面では受動(相手が殴ってくるまで無意味)だが、王手をかけている駒に使えば能動(相手に締め切りを課す)。効果単体で切ってはいけない。

### 基準2: 卓上の負担

属性(陰/陽)の書き換えは**除外**。RULE_SPEC §11.2 により、属性が変わるとそのマスの式神のHPが遡って再計算され、最大4の振れ幅で即死しうる。裁定事故の温床になる。

移動系は移動先が陰/陽マスだとHP±2の再計算が起きるが、これは**召喚時に既にやっている操作と同じ**なので新しい負担ではない。属性マス間の移動(±4スイング)だけプレイテストで見る。

### 基準3: 核心に触る

向き・位置・王手のいずれかに触ること。このゲームの楽しさは以下に集約される(→ `fun-articulation.md` 予定)。

1. 向きを決める一手が、攻撃・反撃・弱点を同時に賭けている
2. 背中を取った/取られた瞬間(死角 = 撃破の約半分)
3. 構え直してから斬れるが、斬ってから隠れられない
4. 王手は「負け」ではなく「見つけなければ負け」
5. 倒すことと陣取ることが同じ行為

## 3. 確定した4枠(2026-07-26)

デッキ = 式神16枚 + 術式4枚 = **20枚**。

| 名(仮) | コスト | 効果 | 役割 | 王手への影響 |
|---|---:|---|---|:-:|
| **旋** | 霊力2 | 盤上の式神1体を**任意の向きに変える**。敵味方を問わず、**すでに攻撃した式神にも使える** | 死角を作る / 斬ってから隠れる | 中立 |
| **守り札** | 生命1 または 霊力1〜2 | 自分の式神1体のHP+3(上限10) | 王手を**通す** | 通す |
| **地脈** | 霊力2 | **誰も乗っていないマス**1つの属性を陰・陽・空のいずれかに変える(**太極は対象外**) | 陣地の質を作る | 中立 |
| **楔** | 霊力2 | 指定したマス1つに楔を打つ。詳細は §3.1 | 王手を遅らせる / **通す** | **双方向** |

### 選定の理由

**崩す側をゼロにした構成。** 最も重い問題は「王手が1試合8.5回発生して通るのは0.84回」であり、有能感(目標実現できる感覚)を最も効率よく壊す構造だったため。この4枚は王手の通過率を下げる方向の手を1枚も含まない。

**旋と楔で詰み筋が1つ組める。** 楔で敵の回転を1→3に封じる → 旋で背中を向けさせる → 死角+2で殴る。相手は向きを直すのに3霊力。4枠しかないデッキで術式2枚が連携するのは価値が高い。

**地脈が唯一「陣地の質」を扱う。** 占拠マス数を動かさないので王手に中立。塗ったマスに合う駒は手札から選べる(デッキに陰8・陽8)ため、これ1枚で属性が操作可能なリソースになる。

### 見送った2案(ストック)

| 名 | コスト | 効果 | 見送りの理由 |
|---|---:|---|---|
| **窮鼠** | 霊力4 / 相手が4マス以上占拠中は1 | 自分の式神1体を任意の空きマスへ移動(向きも自由) | 有能感・自律性の2軸では最高評価だったが、**王手を崩す側**のため。「劣勢時だけ安い」という値付けは先後バランスをカード層で自動補正する実利があり、**新ルールのベースラインで先手勝率が基準外だった場合の第一候補**として保持する |
| **逆手** | 霊力3 | 隣接する自分の式神1体と敵の式神1体の位置を入れ替える(向きは各自維持) | 同じく王手を崩す側。盤面のダイナミズムは魅力だが、属性マスをまたぐとHP再計算が2件発生する負担もある |

**用語**: チームシートでは「**術式**」が正式名称。本書の「スペル」は術式に読み替える。

### 3.1 楔の仕様(要確認)

> **楔**(霊力2) — 盤上のマス1つを指定して楔を置く。そのマスについて、以下のコストが**一律+2**される。
> - そのマスへの**召喚**
> - カード効果によってそのマスへ**式神を移動させる**行為
> - そのマスにいる式神の**回転**(1 → **3**)
> - そのマスにいる式神の**攻撃**(2〜3 → 4〜5)

回転が3倍になるのは重く見えるが、**これは楔の狙いそのもの**。楔を踏んだ駒は向きを直しづらくなる → 死角を晒し続ける → 攻めやすい。遅延・妨害という役割と一致する。

**旋との組み合わせ**: 楔で敵の回転を3にしておき、旋で背中を向けさせ、殴る。相手は直すのに3霊力かかる。4枠しかないデッキで術式2枚が1つの詰みを組めるのは価値が高い。

**未決事項:**

| 論点 | 選択肢 | 推奨 |
|---|---|---|
| 対象 | 相手のみ / 両者 | **両者**。対称ルールのほうが覚えやすく、「自分も踏めない場所を作る」という打ち場所の判断が生まれる |
| 持続 | このターンのみ / 次の自分のターン開始時まで / 永続 | **次の自分のターン開始時まで**。永続は盤面が汚れ、マーカーが溜まる |
| 太極との重複 | 太極は手札からの通常召喚が−1(§9.2、下限0) | 差し引き+1として自然に処理できる。特別裁定は不要 |
| 楔自体のコスト | 1 / 2 | 2。相手に+2を要求する効果なので等価 |

**狙い:** 5マス目のマスに打てば、相手はそこへ召喚するのにC2でも霊力4が必要になる。収入3では1ターン届かない。**禁止ではなく遅延**なので、選択肢を消さずに時間を買える。

### 3.2 現在の4枚への懸念

**王手関連が3枚(守り札・楔・窮鼠)に集中している。** 向きに触るのは惑1枚のみ。

王手が試合の主戦場に戻るのは狙い通りだが(§5参照)、偏りすぎると「王手が起きていない局面で腐るカード」が増える。シミュで各カードの**使用率とターン分布**を取り、王手前後に集中しすぎていないか確認する。偏っていたら楔か守り札を、ストックの逆手・退と差し替える。

## 5. 除外したものと理由(再議論を避けるため)

| 候補 | 除外理由 |
|---|---|
| 地脈 / 断脈 / 転生(属性の書き換え) | §11.2により、属性変更はそのマスの式神のHPを遡って再計算し、最大4の振れ幅で即死させる。卓上の裁定負担が大きすぎる |
| 見切り(死角からの攻撃にも反撃できる) | **受動的**。撃った瞬間に盤面が動かず、読みを外すと何も残らない。加えて死角はこのゲームの最高地点であり、それを抑え込むカードは面白さの山を削る |
| 祈祷(生命+3) | 受動的かつ盤面に何も起こさない |
| 追撃(追加攻撃) / 気合(ATK+2) | 撃破決着を増やす方向。現在の課題(撃破26.3%が多い)と逆行 |
| 集気(霊力+2) / 献身 | 霊力カーブに直撃。先後バランスの主戦場を荒らす |
| 除去(ダメージ・破壊) | 同上。撃破決着を増やす。EOJでも除去は最も重いコスト帯に隔離されている |
| ドロー系 | 毎ターン5枚まで補充されるため価値がほぼゼロ |
| 相手ターンに使えるカウンター | 「自分のターンにしか何もしない」現在の構造を1段複雑にする。初見の説明コストが上がる |

## 6. 数値的な背景(なぜ王手に手を入れるのか)

C3 HP3のLv7ミラー2000試合より:

| | |
|---|---:|
| 王手の発生 | 17,080回 = **8.54回/試合** |
| 制圧決着 | 1,672試合 = **0.84回/試合** |
| 制圧転換率 | **9.8%** |
| 死角率 | **16.5%** |

**1試合に8.5回も王手がかかって、通るのは1回未満。** 個々の王手はほぼ9割崩されており、7/18時点の設計意図「王手は脅威だが、約半分は返せる」から大きく外れている(計測条件が異なるため直接比較は不可)。

**死角率16.5%** は、このゲームで最大の一撃が6ターンに1回しか起きていないことを意味する。増やす手を配るべきで、減らす手ではない。
