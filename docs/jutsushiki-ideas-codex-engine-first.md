# 術式アイデア集 Codex案（エンジン起点の初稿）

Date: 2026-07-27  
種別: 設計アイデアの発散・DSL実装可否調査  
参照: `fenril058/3x3_duel` の `data/effects.json`、`design/software/EFFECT_DSL.md`、エンジン実装

## 0. 前提と判定記号

既に確定している〈旋〉〈守り札〉〈地脈〉〈楔〉、および検討済みの案と同じ効果は提案から除いた。

DSL表現可否は、カード本文だけでなく現在の正本エンジンで最後まで解決できるかを基準にした。

- **○**: 現在の`on_use`、`choose`、`action`、`modifier`だけで実装できる
- **△**: 小さな語彙・対象指定・コスト処理・持続期間の追加が必要
- **×**: 状態保存や盤面全体の原子的な変換など、現DSLの構造を大きく超える

生命コストはゲーム上の候補として有効だが、現在の霊具実装は`card.summonCost`を霊力から支払うだけである。このため、**生命コストを持つ案は効果本体が既存DSLで書けても総合判定を△**とした。

## 1. アイデア本体

### 1. 風送り

| 項目 | 内容 |
|---|---|
| コスト | 霊力2 |
| 効果 | 盤上の式神1体を選ぶ。その式神に隣接する空きマス1つを選び、選んだ式神をそのマスへ移動する。その後、その式神を左右いずれかに90度回転する。 |
| 使った瞬間、卓上で何が起きるか | 敵味方どちらかの駒を隣のマスへ滑らせ、その場で横を向かせる。 |
| 楽しさの根拠 | 位置と向きを同時に変え、攻撃範囲・反撃範囲・弱点の関係を一手で組み替える。読みを当てれば王手を作り、外せば相手に背中を渡す。§4.1の1・2・4・5。 |
| DSL表現可否 | **○**。`choose any unit`→`choose empty cell adjacent_of`→`move`→`rotate`。 |
| 懸念 | 敵を異属性マスへ移すとHPが最大4変動し、移動だけで撃破が起こりうる。効果としては明快だが、属性再計算を忘れやすい。 |

### 2. 羅針

| 項目 | 内容 |
|---|---|
| コスト | 霊力2 |
| 効果 | 味方式神1体を選んで90度回転する。その後、敵式神1体を選んで90度回転する。それぞれの回転方向は個別に選ぶ。 |
| 使った瞬間、卓上で何が起きるか | 自分と相手の駒を1体ずつ手に取り、二つの向きを同時に組み替える。 |
| 楽しさの根拠 | 自分だけを強くせず、双方の構えを変えることで新しい攻防を作る。二つの向きの組合せを自分で決めるため自律性が高い。§4.1の1・3・4。 |
| DSL表現可否 | **○**。別々の束縛に対して`rotate`を2回行う。 |
| 懸念 | 選択が4段階（自軍、方向、敵、方向）になり、デジタルでは軽いが卓上では少し長い。〈旋〉より効果範囲が広いためコスト比較が必要。 |

### 3. 疾駆

| 項目 | 内容 |
|---|---|
| コスト | 霊力3 |
| 効果 | 味方式神1体を選ぶ。その式神を隣接する空きマスへ移動する。その後、さらに隣接する空きマスがあれば、もう1回移動する。2回目は1回目と異なる方向を選んでもよい。向きは変わらない。 |
| 使った瞬間、卓上で何が起きるか | 1体の駒が盤面上を二歩走り、直進も曲がりも選べる。 |
| 楽しさの根拠 | 3x3盤で二歩は大きく、陣取りと死角取りを同じ移動で狙える。向きが残るので、到着後の強さと脆さを移動前に読む必要がある。§4.1の1・2・5。 |
| DSL表現可否 | **○**。同じ束縛を基準に`adjacent_of`→`move`を2回繰り返す。2回目の候補がなければ1回目までを残して不発になる。 |
| 懸念 | 一気に盤面を横断でき、占拠勝利への寄与が大きい。2回の属性再計算が発生しうる。 |

### 4. 二歩陣

| 項目 | 内容 |
|---|---|
| コスト | 霊力3 |
| 効果 | 次の処理を2回行う。「味方式神1体を選び、その式神を隣接する空きマスへ移動する」。2回とも同じ式神を選んでもよい。 |
| 使った瞬間、卓上で何が起きるか | 2体を一歩ずつ動かすか、1体を二歩動かすかを盤面を見て選ぶ。 |
| 楽しさの根拠 | 同じカードが「一点突破」と「布陣変更」の二通りになる。どちらを選ぶかが盤面依存で、自律性が高い。§4.1の4・5。 |
| DSL表現可否 | **○**。`choose ally`→`choose adjacent empty`→`move`を、別の束縛名で2組並べる。同一対象の再選択も現在の候補規則で可能。 |
| 懸念 | 〈疾駆〉より選択肢が多く、最適手探索と卓上の検討時間が増える。 |

### 5. 立て直し

| 項目 | 内容 |
|---|---|
| コスト | 霊力2 |
| 効果 | 味方式神1体を選び、その式神に隣接する空きマスへ移動する。その後、その式神のHPを2回復する。 |
| 使った瞬間、卓上で何が起きるか | 傷ついた駒を戦線から一歩引き、移動先でHPを戻す。 |
| 楽しさの根拠 | 単なる回復ではなく、退路と次の向きを読む局面を作る。王手を受けた駒を救うか、占拠を維持するかの選択になる。§4.1の1・4・5。 |
| DSL表現可否 | **○**。EF-015の移動とEF-029の回復を同じ束縛へ順に適用できる。 |
| 懸念 | 守勢が強くなり長期化を招く可能性がある。移動先の属性でHPが先に変わり、そこでHP0以下なら回復前に撃破される。 |

### 6. 決死行

| 項目 | 内容 |
|---|---|
| コスト | 霊力1 |
| 効果 | 味方式神1体を選び、その式神に1ダメージを与える。生き残った場合、隣接する空きマスへ移動し、90度回転する。このターン、その式神の攻撃コストを1減らす（最低0）。 |
| 使った瞬間、卓上で何が起きるか | 自分の駒に傷を付けて前へ押し出し、向きを変えて攻撃態勢に入れる。 |
| 楽しさの根拠 | HP、位置、向き、残り霊力をまとめて賭ける。成功すれば死角を奪えるが、反撃や次ターンの弱点が重くなる。§4.1の1・2・3・5。 |
| DSL表現可否 | **○**。`damage`→`move`→`rotate`→一時`command_cost attack delta -1`。途中で撃破された場合は後続が対象不在で進まない。 |
| 懸念 | 霊力1としては処理量が多い。C2/C3は自己ダメージの比重が大きく、属性不一致マスへの移動で即死しやすい。 |

### 7. 捨身

| 項目 | 内容 |
|---|---|
| コスト | 霊力1 |
| 効果 | 味方式神1体を選ぶ。このターン、その式神の攻撃コストを0にする。その式神が反撃で受けるダメージは2増える。 |
| 使った瞬間、卓上で何が起きるか | 駒に捨身の印を置き、ただで斬れる代わりに反撃が致命傷になる状態を宣言する。 |
| 楽しさの根拠 | 攻撃できること自体ではなく、「どこから斬れば反撃を受けないか」を強く問う。死角取りを成功させたプレイヤーだけが安全に得をする。§4.1の1・2・3。 |
| DSL表現可否 | **○**。一時`command_cost attack set 0`と、一時`damage taken +2 when counter`を同じ対象へ適用する。 |
| 懸念 | 印やマーカーがないと一時修正を忘れやすい。無料攻撃が霊力経済へ与える影響は要測定。 |

### 8. 受流し

| 項目 | 内容 |
|---|---|
| コスト | 霊力1 |
| 効果 | 味方式神1体を選ぶ。このターン、その式神が攻撃で与えるダメージを1減らし、その式神が反撃で受けるダメージを3減らす。いずれも最低0。 |
| 使った瞬間、卓上で何が起きるか | 攻撃力を落としてでも安全に刃を合わせる「探りの一撃」を選べるようになる。 |
| 楽しさの根拠 | 攻撃を必ず撃破手段にせず、相手の向きや反撃を確認しながら圧をかける別の攻撃目的を作る。局面を消さず、次の応手を生む。§4.1の1・3・4。 |
| DSL表現可否 | **○**。一時`damage dealt -1`と一時`damage taken -3 when counter`。 |
| 懸念 | 数値だけを見ると地味で、卓上の演出には専用の「受流し」マーカーが欲しい。反撃を恐れず削れることで大型への集中攻撃が強まる。 |

### 9. 破戒

| 項目 | 内容 |
|---|---|
| コスト | 霊力2 |
| 効果 | 味方式神1体を選ぶ。このターン、その式神の攻撃に反撃は発生しない。ただし、その式神の攻撃コストは1増える。 |
| 使った瞬間、卓上で何が起きるか | 高い霊力を払って反撃を封じ、正面から安全に斬る権利を買う。 |
| 楽しさの根拠 | 死角を取れない盤面でも攻撃線を作るが、追加支払いにより召喚との競合が生まれる。「今ここで正面突破するか」という自律的な決断になる。§4.1の3・4。 |
| DSL表現可否 | **○**。一時`flag no_counter_against_attacks`と一時`command_cost attack delta +1`。一時flagも`tempModifiers`で解釈される。 |
| 懸念 | 死角を取る価値を相対的に下げる。頻出すると最高地点を削るため、枚数かコストで希少にする必要がある。 |

### 10. 命隠し

| 項目 | 内容 |
|---|---|
| コスト | 霊力1 |
| 効果 | 味方式神1体を選ぶ。このターン、その式神の生命価を4減らす（最低0）。 |

| 懸念 | 生命価の一時変更は見落としやすい。生命決着を減らす方向なので、長期化と大型の使い捨て化を監視する。 |

## 2. 意図的に枠を外した案

以下は既存の却下基準や安全域を意図的に越える。採用を推すという意味ではなく、「卓上で起きること」の上限を見るための案である。

### 16. 伏兵

| 項目 | 内容 |
|---|---|
| コスト | 霊力2 |
| 効果 | 味方式神1体を選ぶ。このターン、その式神が死角から攻撃するとき、与えるダメージをさらに2増やす。 |
| 使った瞬間、卓上で何が起きるか | 「この背後を取った一撃が切り札になる」と宣言し、攻撃線へ伏兵札を置く。 |
| 楽しさの根拠 | 却下基準の「ATK+」に触れるが、正面火力ではなくゲームの最高地点である死角成功だけを増幅する。位置取りを省略せず、むしろ成功条件を尖らせる価値がある。§4.1の1・2。 |
| DSL表現可否 | **○**。一時`damage dealt +2 when blindSpot`。 |
| 懸念 | 撃破数と生命決着を直接増やす。既に死角+2・反撃不能があるため、オーバーキルになりやすい。 |

### 17. 飛石

| 項目 | 内容 |
|---|---|
| コスト | 霊力2 |
| 効果 | 味方式神1体と、その式神に上下左右で隣接する式神1体を選ぶ。最初に選んだ味方式神を、隣接式神を挟んだ反対側のマスへ移動する。反対側が盤外または空きマスでなければ使用できない。向きは変わらない。 |
| 使った瞬間、卓上で何が起きるか | 自分の駒が別の駒を飛び越え、反対側へ着地する。 |
| 楽しさの根拠 | 既存の「隣へ動く」だけでは作れない、駒を壁ではなく踏み台として読む新しい空間パズルになる。撃破せずに死角と占拠を作れる。§4.1の1・2・5。 |
| DSL表現可否 | **△**。基準ユニットと隣接ユニットから反対側座標を導出する`jump_over`、または相対位置付きセルselectorが必要。 |
| 懸念 | 斜めや向きとの混同を避ける図解が必要。属性マスへの着地処理は通常移動と同じ。 |

### 18. 面写し

| 項目 | 内容 |
|---|---|
| コスト | 霊力2 |
| 効果 | 盤上の式神2体を順に選ぶ。2体目の向きを、1体目と同じ向きにする。90度制限は適用しない。 |
| 使った瞬間、卓上で何が起きるか | 一方の駒の向きを見て、もう一方をまったく同じ方向へ向ける。 |
| 楽しさの根拠 | 「何度回すか」ではなく「誰の構えを写すか」を問う。180度変更も起こりうるが、参照元を盤面から選ぶ必要があり、万能な任意回転とは違う読みになる。§4.1の1・4。 |
| DSL表現可否 | **△**。`set_facing`と`from: "$unit"`が必要。既存`rotate`は90度しか扱えない。 |
| 懸念 | 〈旋〉と役割が近い。参照元が必要という制約が十分に差別化になるか確認が必要。 |

### 19. 裏門

| 項目 | 内容 |
|---|---|
| コスト | 霊力3 |
| 効果 | 敵式神1体を選ぶ。選んだ敵式神の死角に含まれる空きマス1つを選び、味方式神1体をそのマスへ移動する。移動する味方式神は、移動先に上下左右で隣接していなければならない。向きは変わらない。 |
| 使った瞬間、卓上で何が起きるか | 味方の駒を敵の背後へ滑り込ませ、次の一撃を目に見える形で予告する。 |
| 楽しさの根拠 | 直接ダメージを与えず、最高地点である背後取りそのものをカードで作る。ただし攻撃は別に必要で、相手に応手が残る。§4.1の2・4・5。 |

| 懸念 | 条件を満たすと強いチェック生成器になる。カードで死角を作ることが通常の位置取りを省略しすぎないかを見る必要がある。 |

### 20. 借霊

| 項目 | 内容 |
|---|---|
| コスト | 生命2 |
| 効果 | 霊力を4得る。 |
| 使った瞬間、卓上で何が起きるか | 生命を2点削り、その場で霊力を4点増やして召喚と攻撃の選択肢を開く。 |

## 3. エンジン起点: 既に表現できる未使用の型

現行31効果とDSL実装を比較すると、以下は**エンジンに語彙があるが、既存効果では使われていない、または霊具では未使用**だった。

| 型 | 現在できること | 使える発想 | 注意 |
|---|---|---|---|
| `choose.count > 1` | 異なる複数の式神を順に選び、1つの束縛として後続actionへ渡す | 〈双輪〉〈連環〉のような2体セット | `move`と`rotate`は実装が束縛の先頭1体しか処理しない。また、霊具の使用可否チェックは必要数を見ず候補1体以上で許可するため修正が必要 |
| `choose.auto: random` | 候補からシード付きで対象を自動選択する | 〈乱風〉のような低コスト・部分制御 | 紙ではダイスやカード番号などランダム手段を別途決める必要がある |
| `side: any` | 敵味方を問わず盤上の式神を候補にする | 〈風送り〉のような文脈で攻守が変わる術式 | 現行霊具の単体選択はallyかenemyのみ |
| 選択対象への一時`command_cost` | 選んだ式神だけ攻撃・回転コストを固定または増減する | 〈捨身〉〈双輪〉〈連環〉 | 現行`command_cost`は式神の常在効果EF-001だけ。一時修正は未使用 |
| 選択対象への一時`damage`条件修正 | `blindSpot`、`counter`、`attackType`条件付きで与ダメ・被ダメを増減する | 〈受流し〉〈伏兵〉 | 現行の条件付きdamage modifierはすべて式神の常在効果。術式からの一時付与は未使用 |
| 選択対象への一時`flag` | `no_counter_against_attacks`等をターン終了まで与える | 〈破戒〉 | schema上のmodifierと`tempModifiers`処理は共通なので既存flagを一時付与できる |
| 選択対象への一時`lifeValue`修正 | 生命価をターン終了まで増減し、最低値も指定できる | 〈命隠し〉〈肩代わり〉 | 現行は盤上の常在EF-027だけ。卓上では生命価マーカーが必要 |
| 同じ束縛への複数action | 移動、回転、回復、修正を順番に解決する | 〈風送り〉〈決死行〉〈立て直し〉 | 各段階で対象が撃破・消失した場合、後続は可能な範囲だけ実行される |
| 途中まで解決して不発 | 後段の候補がなくても前段を巻き戻さない | 〈疾駆〉の「一歩は動けたが二歩目は不可」 | カード本文に「可能なら」を書かないと体感と裁定がずれる |

### 3.1 文書上は可能だが、現実装に境界があるもの

1. **霊具には盤上の発生源がない。** `on_use`は`sourceId=-1`、`sourcePos=null`で解決される。そのため、霊具が直接`area: adjacent_self`や`area: attack_range`を使っても候補は0件になる。まず盤上の式神を選び、その束縛に対して`adjacent_of`を使う必要がある。
2. **`move`と`rotate`は複数対象束縛の先頭1体だけを処理する。** `count: 2`と組み合わせて2体同時移動・回転を期待してはいけない。複数回のchoose/actionを書くか、エンジン語彙を追加する。
3. **1つの効果に複数clauseを書けるが、霊具使用処理は最初の`on_use` clauseだけを取得する。** 術式の複合効果は、現状では1 clause内の複数stepとして書く必要がある。
4. **持続期間は`end_of_turn`だけ。** 「次の相手ターンまで」「次の自分のターンまで」は現在の状態モデルでは表現できない。相手ターンに作用する封印・結界・罠は追加実装が必要。
5. **生命コストは効果DSLではなくカード使用コスト側の未実装事項。** `gain_mana`や`heal`など効果本体が既存語彙でも、生命を支払うカードは総合的には△になる。
6. **一時`stat: hp`は表示上の導出値には反映されるが、現在HPそのものを増減しない。** HPを実際に増やす術式には`heal`を使うべきで、「最大HPだけ上げる」効果は別途裁定と実装が必要。
7. **複数選択を要求する霊具の事前チェックが不足している。** `count: 2`でも候補が1体いれば使用宣言とコスト支払いが通り、その後のchooseで候補不足として不発になる。2体必須の術式を入れる前に、最初のchooseの必要数まで確認する必要がある。

## 4. 初回試作で触りたい案

採否ではなく、紙で「使った瞬間の楽しさ」を見分けやすい順の試作候補。

1. **風送り**: 位置と向きが同時に動き、このゲームらしさが最も直接出る。
2. **決死行**: 新しい回転→攻撃ルールと霊力配分を、一枚のリスク選択にまとめられる。
3. **受流し**: 攻撃を「撃破以外の目的」に変えられるかを試せる。
4. **双輪**: 数値火力を足さず、向きの選択量だけを増やす。
5. **飛石**: 新語彙が必要だが、既存カードでは起こらない卓上の瞬間を最も明確に作る。

〈破戒〉〈伏兵〉〈借霊〉は比較対象として価値があるが、死角・反撃・霊力経済というゲームの中核を直接緩めるため、初回の標準4枠より「境界確認用」の位置づけがよい。
