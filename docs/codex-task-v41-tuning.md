前提資料:

- `docs/baselines/v4-probe-paper.md` — 出発点(v4+紙: 先手55.3% / 生命勝ち38.6% / 平均13.37R / 返し77.5%)
- `docs/handoff-analysis-kpi.md` — 作法(特に「ノブの効き目は環境依存」「候補構成は必ず1本として再実測」)

## 方針(ユーザー決定)

v4のルール・数値(撃破時霊力2 / 弱点+1 / **C2:HP3・C3:HP4**・C4:HP5 / 陰陽2属性+盤面+太極召喚−1 / 敵味方を問わない隣接配置 / 現在の勝利条件)は**今回の基準案として固定**。触らない。

※C3のHPは2(2026-07-19ユーザー指定。v4プローブ時の3からさらに−1)。**v4-probe-paperはC3:HP3での測定**のため、本掃引の対照として使う際はこの差分に注意。R0(下記)で対照を取り直す。

チューニングはv4に含まれない数値で行う:

- **先後**: 後手初期霊力(dmは先後ノブとして使わない裁定を維持)
- **生命経済**: 初期生命 / 生命価カーブ

## 暫定チューニング目標(仮置き。最終判定はユーザー+チーム)

| 指標 | 目標 |
|---|---|
| 先手勝率 | 50±2pt(最優先) |
| 生命勝ち率 | 10〜20%(v4の生命プレッシャーは残す。38.6%は過剰) |
| 占拠勝ち率 | ≥75% |
| 平均R | 10.5〜12.5 |
| 王手返し率 | ≤70%目安 |

## 実行(各2000試合、seed 20260702、oracleあり、depth 6、全ランv4骨格+紙)

| ラン | 変更 | 狙い |
|---|---|---|
| **R0** | **v4骨格(C2:HP3/C3:HP4版)そのもの**(後手4・生命15・生命価1/1/1/3/3/4) | **本掃引の対照**。v4の正式HP仕様を基準にする |
| H1 | R0から後手初期霊力 4→**5** | 先手勝率の補正量を測る(環境依存なので実測必須) |
| L1 | 初期生命 15→**18** | 生命勝ちの用量反応① |
| L2 | 初期生命 15→**20** | 生命勝ちの用量反応② |
| L3 | 生命価 1/1/1/3/3/4→**1/1/1/2/2/3** | 高コスト撃破の出血を軽減(生命15のまま) |
| C1 | **H系の最良 × L系の最良の組み合わせ**(H1の結果とL1〜L3の結果を見て自分で選定) | v4.1候補の確認ラン(相互作用込みの実測) |

- H1で足りない/過剰なら、C1の前に後手6または他の刻みを1本追加してよい(判断根拠を記録)
- L系がどれも生命勝ち20%超のままなら、C1は保留し「第2段レバー案(ATKカーブ・返し関連)」の提案に切り替える

## 計測・報告

- 考察: 暫定目標に対する到達度、C1をv4.1候補として推せるか、残る課題
