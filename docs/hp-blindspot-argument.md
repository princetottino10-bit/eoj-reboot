# 属性ボーナスが数値上機能していない

Date: 2026-07-25 / 対象: Ver1_無効果(正本 `vanilla-4`)

---

## 事実

デッキ16枚のうち**8枚がATK2**(子鬼×4、C4帯×4)。その死角攻撃は **2 + 2 = 4ダメージ**。

C2鬼火・C3子鬼の **HPは2**。属性一致マスに乗ると **2 + 2 = 4**。

### 属性マスに乗っても、主力の死角攻撃1発でちょうど死ぬ。

乗っても乗らなくても結果が同じなら、属性マスを取る理由がない。陰2マス・陽2マスしかない属性マスを奪い合う設計が、数値上まったく機能していない。

同じ理由で**死角も機能していない**。正面からのATK2(2ダメージ)でHP2は死ぬので、わざわざ背後に回る必要がない。

---

## 直し方

| 手当て | 属性マス上で主力の死角攻撃を |
|---|---|
| 現行(HP2・死角+2) | **耐えられない**(4 vs 4) |
| **HP3にする** | 耐える(5 vs 4) |
| 死角を+1にする | 耐える(4 vs 3) |

**HP3を推す。** 死角+2を保てば「正面では死なない・死角なら死ぬ」となり、背後を取る必然性も同時に戻る。死角+1は看板メカニクスの威力そのものを削ってしまう。

---

## 実測(ミラー2000試合)

HPを3/4に上げると:

| | 現行 HP2/2 | HP3/4 |
|---|---:|---:|
| **占拠勝ち** | **11.8%** | **45.6%** |
| 生命勝ち | 88.0% | 53.9% |
| 撃破/試合 | 16.93 | 14.54 |

現行構成は**9割が削り合いで決着**していて、5マス制圧という勝利条件がほぼ死んでいる。HPを上げるだけでここまで戻る。

**なお45.6%でも「陣取りが主役」には足りない。** 問題はHP1つでは終わらない。だからこそ、まずここから手を付ける必要がある。
