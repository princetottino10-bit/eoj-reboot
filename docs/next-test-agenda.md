## 1. 手札の詰まりと、術式の霊力化(本命の議題)

### 何が問題か

`MAX_HAND=5` の「5枚まで補充」は、裏を返すと**手札が5枚あると1枚も引けない**。霊力収入3に対して C5〜C7 を抱えると出せない札が居座り、**デッキが止まる**。捨てる手段がないと自力で解けない。

2026-07-28 の紙テストで **3ターン目に手札5枚中5枚が術式**という事故が実際に起きている。

### 案 — 術式の霊力化

> **術式は、使用する代わりに捨てて霊力1を得てもよい。1ターン1回。**

**共通ルールとして書く**のが最も効率がよい。個別のカードテキストではなく1行のルールにすると:

- **新しい動詞を1つも増やさない**(既存の「捨てる」と「霊力を得る」の組み合わせ)
- **11種すべてにモード選択が付く** = 全部の自律性が上がる
- カードテキストは1行も増えず、習得コストは1回きり

### 検算は通っている(ただし境界ちょうど)

`effect-design-guidelines.md` 原則1 のチェック式:

```
効果1回の霊力生成 ≤ 発動コスト + カード1枚分の機会費用
        1        ≤      0      +          1
```

**等号ちょうど**。したがって **霊力2にした瞬間に破綻する**(2 ≤ 1 が偽)。1が上限で動かせない。

**回数制限が要る理由はループ防止ではなく、収入の上限管理。** 手札5枚を全部換えれば +5霊力で、収入3が8になる。ループではないが壊れる。

### 卓で決めたい矛盾

**1ターン1回だと、詰まりの解消が遅すぎる。** 5枚詰まりは1枚ずつでは5ターンかかる。**詰まりを直す機構なのに、詰まっているときほど効かない。**

| 案 | 詰まり解消 | リスク |
|---|---|---|
| 霊力化のみ・1ターン1回 | 遅い | 事故時に機能しない |
| 霊力化・枚数無制限 | 速い | 収入が壊れる |
| 霊力化1回 + 単純 discard は無制限 | 速い | ルールが2本になる |

**進め方の推奨: まず霊力化だけを入れて回す。** `effect-design-guidelines.md` 原則6「1変数ずつ」に従い、2つ同時に入れない。詰まりの事故が実際に頻発することを確認してから discard を足す。

### 設計上の注意3点

- [ ] **パスに紐付けないこと。** 「召喚の代わりに」ではなく「**メインフェイズ中に1回**」にする。パス限定にすると、2026-07-08 に議論された**先手初手パス問題**(実質 先手4／後手6 で始められる)を強めてしまう
- [ ] **式神の詰まりは霊力化では解けない。** 「手札が5と7しかない、霊力4」というケース(2026-07-14)はそのまま残る。discard とは競合ではなく**補完**の関係
- [ ] **記録票に「霊力に変えた回数」を別枠で足す。** これを分けて取らないと `jutsushiki-deck-patterns.md` §6 の「一度も使わなかったカードは最も重要な情報」という判定が濁る。**霊力化された回数が多いカードは、実質「使いどころが見えなかったカード」**

### 副産物 — 術式の枚数論争が動く

出口ができると **16+8(24枚)でも事故りにくくなる**。`playtest-2026-07-28.md` §4 で割れたまま止まっている枚数の議論は、霊力化を入れてから判断したほうがよい。
