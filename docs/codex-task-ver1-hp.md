# Codex Task: Ver1構成のHP掃引(属性ボーナスと死角の機能回復)

Status: 実行待ち
Date: 2026-07-25
前提: `docs/baselines/ver1-baseline.md`(仕様準拠エンジンでのVer1基準)、`docs/current-spec-ver1.md`

## 背景と狙い

Ver1基準(2000試合)の結果:

- **先手49.7%**(太極の仕様修正で先後バランスは解決)
- **占拠11.8% / 生命88.0%** — 陣取りゲームとして機能していない
- 撃破16.93/試合、4チェック返し率90.6%(オラクル上限91.4%)

診断: **C2/C3のHP2が低すぎ、属性ボーナスと死角の両方を無意味にしている**。

| | HP | 属性+2込み | 主力ATK2の死角攻撃(4ダメージ) |
|---|---:|---:|---|
| 現行 | 2 | 4 | **ちょうど落ちる**(属性マスに乗っても守れない) |
| HP3案 | 3 | 5 | **耐える**(残1) |

さらに正面ATK2が2ダメージなので、**HP2は正面で即死=死角を突く必要がない**。HP3なら正面では落ちず(残1)、死角(4)でのみ落ちるため、位置取りが決定打として復活する。

期待する連鎖: HP↑ → 撃破↓ → 生命ドレイン↓ → 生命勝ち↓。同時に**式神が硬い=王手を返しにくい** → 返し率↓ → **占拠勝ち↑**。占拠決着が戻るので平均Rも短縮方向。

## 実行(各2000試合、seed `20260702`、depth 6、oracleあり、仕様準拠エンジン)

Ver1構成(vanilla-4の固定カードデータ)から **C2/C3のHPのみ**を変更する。C4以上・再命令コスト(2/2/2/3/3/3)・属性割当・形状・生命価・定数はすべて据え置き。

| ラン | C2 HP | C3 HP | 位置づけ |
|---|---:|---:|---|
| **V0** | 2 | 2 | 対照(=ver1-baseline の再掲でよい。再実行不要なら既存値を引用) |
| **H-A** | 3 | 3 | 最小変更。属性+2で5になり死角ATK2を耐える |
| **H-B** | 3 | 4 | 7/18仕様のHP(紙ルール下で占拠91%の実績) |

## 計測・報告

- 全KPIを「V0 / H-A / H-B」の3列比較
- **特に注視**: 占拠勝ち率 / 生命勝ち率 / 撃破数 / 4チェック返し率(とオラクル上限) / 平均R / 先手勝率
- 追加で取れれば: 属性一致召喚率、属性ボーナス適用回数、死角攻撃率・死角撃破率
  (「属性マスが避難所として機能し始めたか」「死角が必須手段になったか」を見る指標)

## 判定の目安(参考。最終判定はユーザー+チーム)

- 占拠勝ち: **60%以上**なら陣取りゲームとして復活と見なせる
- 生命勝ち: 40%以下
- 先手勝率: 50±2ptを維持していること(HPが先後バランスを壊していないか)
- 撃破: 8〜12程度まで下がるか
