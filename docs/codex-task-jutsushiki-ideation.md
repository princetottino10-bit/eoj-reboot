## 1. 依頼の要旨

3x3 Duel に加える **術式**(式神ではないカード)のアイデアを出してほしい。

**判断基準は「楽しいかどうか」を最優先**とする。バランスやKPIは後で調整できるが、面白くない効果は何をどう調整しても面白くならない。

**あわせて、正本の効果DSLで表現できるかを判定してほしい。** ここが今回codexに頼む一番の理由で、`data/effects.json` と `design/software/EFFECT_DSL.md` を読める立場から「エンジンが既に持っている語彙」を起点に発想すると、人間側とは違う案が出るはずだ。

## 2. 前提となるルール(2026-07-26改定を含む)

### 2.1 再行動(**新ルール。ここを間違えると案が全部ずれる**)

| 行動 | コスト | 制限 |
|---|---:|---|
| 回転 | **1**(一律・コスト帯によらない) | 1ターン1回 = **90度まで** |
| 攻撃 | `commandCost`(2/2/2/3/3/3) | 1ターン1回 |
| 順序 | **回転 → 攻撃 のみ** | **攻撃したらその式神の再命令は終了。攻撃後の回転は不可** |

**回転攻撃は廃止された。** 旧ルールは「1回分の支払いで回転枠と攻撃枠を両方消費する」割引パックだったが、それが無くなり回転の定価が下がった。

**重要な帰結: 盤上の式神は1ターンに180度回れない**(召喚時のみ向き自由)。

### 2.2 盤面と属性

```
空 陰 空
陰 太極 陽
空 陽 空
```

- 陰2マス / 陽2マス / 空4マス(四隅) / 太極1マス
- 同属性マスで HP `+2`、対立属性マスで HP `-2`(陰↔陽が対立、空は中立)
- 太極は無属性。**手札から太極へ通常召喚する場合のみ消費霊力−1**(下限0)

### 2.3 主要定数

`START_LIFE 15` / `MAX_HP 10` / `DECK_SIZE 16`(術式導入後は20案) / `MANA_PER_TURN 3` / `霊力上限 15` / `WIN_CONTROL 5` / `BLIND_SPOT_BONUS 2` / `ATTRIBUTE_HP_BONUS 2` / `DESTROY_MANA_GAIN 2` / `START_MANA 先手3・後手4` / `MAX_HAND 5`

生命価: C2〜C4 = 1 / C5・C6 = 3 / C7 = 4

デッキ(vanilla-4): 鬼火C2×4 / 子鬼C3×4(**HP3**) / 槍霊C4 / 薙刀霊C4 / 鬼C4×2 / 両面C5 / 仁王C5 / 九尾C6 / 龍C7

### 2.4 術式の使用ルール(案)

> 術式はメインフェイズ中、召喚より前に、1ターン1枚まで使用できる。霊力を消費するが召喚枠は消費しない。

## 3. コスト通貨は2つしかない

| 通貨 | 使えるか | 理由 |
|---|---|---|
| **霊力** | ○ | 収入3/ターン。**召喚と直接競合する**ので、放置しても自制が効く |
| **生命** | ○ | START_LIFE 15。**補充されない唯一の通貨**。霊力に触らないので召喚テンポを落とさずに効果を刷れる |
| 手札 | **×** | `MAX_HAND` まで毎ターン自動補充され、デッキ切れも無い(墓地シャッフル)。捨ててもすぐ埋まり、むしろデッキが回って質が上がる。**コストとして機能しない** |

生命の相場観: 1 ≈ 低コスト式神1体分 / 3 ≈ 九尾・仁王1体分 / 5以上 = 切り札級。

チームでは既に〈VP→術者ライフ制〉が採用済みで、「ウルトはライフを消費して放つ」という方針がある。**生命コストはこのゲームの既存の語彙**。

## 4. 「楽しい」の定義(このプロジェクトでの合意)

### 4.1 このゲームの楽しさは5つ

1. **向きを決める一手が、攻撃・反撃・弱点を同時に賭けている。** 北を向くとは「脅威は北から来る」に賭けること。当たれば殴れて反撃もできる。外れれば背中を取られて何もできない。**強さと脆さが同じ選択から正反対の方向に生まれる**
2. **背中を取った/取られた瞬間。** 死角からの一撃は+2かつ反撃不能で、撃破の約半分がここを通る。1〜2ターン前の読みへの答え合わせになっている
3. **構え直してから斬れるが、斬ってから隠れられない。** 殴るという決断は必ず誰かに背中を晒す
4. **王手は「負け」ではなく「見つけなければ負け」**
5. **倒すことと陣取ることが同じ行為。** 戦闘リソースと得点リソースが分離していない

### 4.2 判定基準

自己決定理論の2軸で見る。

- **有能感** — 目標を実現できる感覚。読みが盤面の上で報われるか
- **自律性** — 自分の意志で選んでいる感覚。選択肢が増えるか

そこから導かれる実務的な問い:

| 問い | 落ちる例 |
|---|---|
| **使った瞬間、卓上で何が起きるか** | 「HPの数字が3増える」は弱い。「相手の駒を掴んで回す」は強い |
| **相手に応手を強いるか** | 局面を**作る**カードか、**消す**カードか |
| **読みを外した時にも何かが起きるか** | 空振りが不可視だと使う判断が痩せる |
| **効果が受動的でないか** | 「相手がこう来たら効く」は撃った瞬間に何も起きない。**判定は"条件"ではなく"効果"で行う**(発動条件が受動的でも効果が能動的なら合格) |

**文脈で裏返る効果に注意。** HP+3 は何も起きていない盤面では受動的だが、王手をかけている駒に使えば相手に締め切りを課すので能動的になる。効果単体で切ってはいけない。

## 5. 卓上の負担という制約

これは物理カードゲームであり、裁定は人間が行う。

**属性の書き換えは要注意。** RULE_SPEC §11.2 により、マスの属性が変わるとそこに立っている式神のHPが**遡って再計算**され、最大±4振れて即死しうる。同じ理由で、**駒の属性を変える効果も危険**(乗っているマスとの関係が変わるため)。

安全にする定石は「**誰も乗っていないマスにのみ作用させる**」「**自分の駒にのみ使えるようにする**」のいずれか。前者は計算そのものを発生させず、後者は「意図しない即死」を「プレイヤーの判断ミス」に変える。

**相手のターンに発動するカードは避けたい。** 「自分のターンにしか何もしない」という現在の構造を1段複雑にし、初見の説明コストが上がる。

## 6. 既出の案(重複を避けるため)

### 6.1 確定した4枠

| 名 | コスト | 効果 |
|---|---|---|
| 旋 | 霊力2 | 盤上の式神1体を**任意の向きに変える**。敵味方問わず、**すでに攻撃した式神にも使える** |
| 守り札 | 生命1 or 霊力1〜2 | 自分の式神1体のHP+3(上限10) |
| 地脈 | 霊力2 | **誰も乗っていないマス**1つの属性を陰・陽・空のいずれかに変える(太極は対象外) |
| 楔 | 霊力2 | マス1つを指定。そのマスへの召喚/移動、そこにいる式神の回転・攻撃のコストが**一律+2** |

### 6.2 検討済み(採用しなかったが良案)

窮鼠(霊力4 / 相手が4マス以上占拠中は1・任意の空きマスへ移動、向きも自由) / 逆手(隣接する自分と敵の位置を入れ替え) / 傀儡(敵1体を指定の向きに変え、その式神に攻撃させる) / 反魂(生命3・墓地の式神を召喚コスト無しで配置) / 円舞(自軍全体を同方向に90度回転) / 中庸(太極にいる駒が全方位攻撃) / 静止(敵1体が次の自分のターンまで回転できない) / 加護(1体の再行動コストが0) / 早駆け(もう一度攻撃) / 贄(生命2→霊力4) / 殉じる(自分の式神を還して生命価を払わず霊力回収) / 布陣(このターン召喚をもう1回) / 影渡 / 退 / 撤収 / 陣替 / 呪縛 / 号令 / 看破 / 天地(盤ごと回転=検討の結果no-opと判明)

詳細は [`spell-candidates.md`](spell-candidates.md)。

### 6.3 却下した案とその理由(再提案しないこと)

| 案 | 理由 |
|---|---|
| 転生(式神の属性を陰↔陽に変える) | §5の±4問題。自分限定なら安全だが、**手札に陰8・陽8いるので塗ったマスに合う駒を選べばよく、機能が重複** |
| 見切り(死角からの攻撃にも反撃できる) | 受動的。かつ死角はこのゲームの最高地点であり、抑え込むカードは面白さの山を削る |
| 祈祷(生命+3) | 受動的かつ盤面に何も起こさない |
| 追撃・気合(ATK+) | 撃破決着を増やす方向 |
| 集気(霊力+2) | 霊力カーブに直撃。先後バランスの主戦場を荒らす |
| 除去(ダメージ・破壊) | 同上。撃破を増やす |
| ドロー系 | 毎ターン`MAX_HAND`まで補充されるため価値がほぼゼロ |

## 7. 求める出力

`docs/jutsushiki-ideas-codex.md` に保存。

### 7.1 アイデア本体

**15案以上。** 各案について:

| 項目 | 内容 |
|---|---|
| 名称(仮) | 日本語。テーマは陰陽・呪術 |
| コスト | 霊力 or 生命。数値まで |
| 効果 | **裁定できる精度で**。曖昧語を残さない |
| **使った瞬間、卓上で何が起きるか** | **1文で。これが最重要項目** |
| 楽しさの根拠 | §4.1の5つのどれに効くか |
| DSL表現可否 | ○(既存語彙で書ける) / △(語彙の追加が要る・何が要るか) / ×(構造的に無理・なぜ) |
| 懸念 | バランス・卓上負担・ルール干渉 |

### 7.2 意図的に枠を外した案を3件以上含めること

§6の却下理由に触れるものでもよい。**その場合は「なぜ却下基準を超える価値があるのか」を書く。** 安全な案だけを並べられても、いま欲しいものにならない。

### 7.3 エンジン起点の節を設けること

`data/effects.json` と `EFFECT_DSL.md` を読み、**「エンジンが既に表現できるのに、まだ誰も使っていない効果の型」**を列挙してほしい。人間側は効果から発想しているので、実装語彙から逆算する視点は codex にしか出せない。
