## 付録: 実装メモと裁定

仕様が一意に定まらなかった箇所の処理。数値の解釈ではなく実装の事実として記す。

| 論点 | 採った処理 |
|---|---|
| `summonCostScale:"half"` と太極−2の順序 | 半減を先に適用し、その結果に太極割引(下限1)をかける。例: 召7 → 4 → 太極2 |
| `summonCostScale` と霊具 | 霊具のコストは召喚ではないため半減の対象外(印刷コストのまま) |
| `moveOnKill` とAoE | 「1回の攻撃で撃破された敵がちょうど1体」のときのみ移動。AoEでも同条件で移動しうる。味方のみを撃破した場合は移動しない |
| `moveOnKill` の処理順 | 撃破解決の後、反撃判定の前。反撃の射程判定は移動後のマスで行う |
| `counterMode:"single"` の同値処理 | 実効HP最大が複数いる場合は uid の小さい方(決定的) |
| `incomeTiming:"turn_end"` の初回 | 収入は毎ターン終了時に発生する(開始時の収入は行われない)。ターン1の収入はターン1終了時に入るため、各プレイヤーが受け取る収入の回数は turn_start と同数 |
| `deckOutMode:"second"` の判定点 | 墓地シャッフルは `drawOne` 内でカウントし、ターン開始時の効果ドロー後とターン終了処理の末尾で終了判定する |
| `lifeValueEnabled:false` とAI | 評価関数の life 項を落とした(`W.life` を0扱い)。撃破時の生命減少と生命0敗北の両方が無効 |
