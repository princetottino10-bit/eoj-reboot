## 0. 実装方針(確定済み)

- DSL化は不要。`src/effects.ts` 1モジュールに cardId ベースのフック実装でよい
- フック点の目安: onTurnStart / modifyAttackDamage / onAfterAttack / onSummon / onUnitDestroyed / canRotateCommand / rotateCommandRedirect / 霊具アクション
- CLIに `--effects on|off`(既定 on)。**off で従来挙動と完全一致**(既存56テストが全通過することで担保)
- 霊具はアトミックアクション: コスト支払い → 効果解決 → 墓地。**1ターンの使用回数制限なし**(霊力のみが制約)。greedy/beam の候補列挙に追加
- UIにも霊具使用と効果発動ログを反映
- 各効果に受け入れテスト最低1件

## 3. 競合・解決順

- 同一攻撃に複数のダメージ修正(例: 影鬼の+1と死角+2、提灯の+1)は**すべて加算**
- 照魔鏡のATK参照と一目鬼の巨撃が両立する状況は現デッキでは発生しない(別カード)。将来のため: **ATKの置換(照魔鏡)を先に解決し、その後に加算修正**
- マヨヒガ対象のユニットは: 攻撃対象に選べない / AoEにも当たらない / 霊具の対象に選べない / 継承召喚の対象にできない / 占拠・リーチ・チップの計算から除外 / 自身はコマンド不可(命令の対象にならないため)。**盤面のマスは物理的に塞いだまま**(そのマスへは召喚できない)
- 玖龍街が複数(ミラーで両者が出した)場合: 双方が回転コマンド不可。各自の玖龍街の代理回転は可(それは「効果」側の扱い)
- 効果によるHP増加はすべて「実効最大まで」(鬼の酒のみ例外で7固定・上限10)
- 灯籠の精が範囲攻撃で他の味方と同時に撃破された場合、同じ解決で撃破される味方はHP+1の対象外(盤上の並び順に依存しない)
- 家鳴り(tm18)で指定できる向きは90度の2方向だけ(180度や向きを変えない指定は不正)。shuten-kyuryu の家鳴り(sk18)は今と違う向きならどれでも
- 術式・範囲の攻撃(tm17 玖龍街)は、9/13ルール(r0913/r0914、`jutsuAoeSparesAllies`)では範囲内の味方に当たらない

### 5.3 裁定(文面から決めたもの。チームの確認待ち)

1. **灯籠の精**: +2 を受けるのは、撃破時に盤上に残る味方(同じ解決で撃破される味方を除く・隠れていない)のうち**召喚コスト最大**の1体(同コストは先に出た方)。その1体がHP満タンなら不発(他の味方には回さない)。実効最大HPまで
2. **変面**: 回復量は ceil(その時のATK/2)。実効最大HPまで
3. **僵尸公主**: 反撃撃破の移動も、攻撃撃破と同じく「移動先で自分のHPが0以下になるなら動かない」。反撃を合計で受ける旧方式(`counterResolve sum`)で使うときは、合計が攻撃側のHPに達した反撃を撃破した反撃とみなす
4. **【再生】**: HP+1 は**攻撃の解決(反撃を含む)が終わった後**、生き残っていれば。実効最大HPを超えない。HP満タンでも選べる(予測に「HP+1」が出るので無駄打ちは見える)
5. **【飲酒】**: ATK+1 は攻撃にだけ効き、反撃には効かない
6. **反撃のダメージ**: 反撃は印刷のATKのまま(提灯の+1・影鬼・巨撃・渾身・飲酒など「攻撃の際」の修正は反撃に乗らない。従来の規則のまま)
7. **反撃できる式神(案A)**: 被弾して生き残った敵のうち、死角からの攻撃でない・ATKと反撃範囲がある・**物理の式神**・反撃範囲に攻撃側がいる、の全部を満たすもの。術式の攻撃には誰も反撃しない(従来どおり)
8. **反撃の順番を聞く場面**: 反撃する式神が2体以上で、**順番によって結果の盤面が変わるとき**だけ(今のカードでは、僵尸公主を含む2体以上の反撃が攻撃側を撃破するとき)。変わらないときは既定の順(盤上の並び順)で黙って解決する。聞いている間はルール・カードの途中変更を受け付けない(選び終わってから)
9. **茨木の左腕**: 「正面方向」= その式神の向きの直線上(盤の端まで)。空きマス・**味方**・隠れた式神(マヨヒガ)は飛ばして、最初の敵を狙う(味方は遮らない)。そういう敵がいなければ使えない。3ダメージは攻撃ではない(反撃・死角なし)
10. **拳 / 握**: 拳 = 使った式神の向きへもう1マス、握 = 使った式神の側へ1マス。行き先が盤外・どれかの駒がいる(隠れた駒・使った式神自身を含む)なら動かない。3ダメージで撃破されたら動かない。動いた駒は向きを保ち、**移動先の属性がすぐ効く**(HPが0以下になればその場で撃破、撃破したのは霊具を使った側)。動けない場合も拳/握はどちらかを選ぶ
11. **閻魔獄卒棒**: 「隣り合う」= 上下左右と**斜め**の8マス。「死角以外」= 霊具を使う式神自身の死角のマス。隠れた式神は選べない。「酒呑一門」はパックの一門(clan)で判定する(カード編集では変わらない)。5ダメージは攻撃ではない(反撃・死角なし)
12. **霊力価の受け取り**: 撃破した側(味方を巻き込んで撃破したら自分、渾身の自滅は誰も得ない、霊具の撃破は使った側、反撃の撃破は反撃した側)。霊力上限15で切る。継承召喚で墓地に行く式神は撃破ではないので霊力価は出ない
13. パックの `lifeValue` には霊力価と同じ数を入れてある(生命ありの旧ルールでこのパックを使ったときだけ意味を持つ)。旧パックの霊力価は floor(召喚コスト/2)(=半額・切り捨ての撃破報酬と同じ)

### 5.4 画面

- 生命が無効のとき、名札・結果・予測・記録から生命を消す。札の右下は生命価(冷たい炎)の代わりに**霊力価(霊力の星)**
- 撃破の演出: 霊力価の印が**撃破した側の霊力**へ飛び「+N」
- 再生・飲酒は丸いメニューに出て、確定前の予測に追加の霊力と効果が入る
- 茨木の左腕: 使う式神を選ぶ →【拳】/【握】それぞれの結果(ダメージ、HPの前→後、撃破、動く先)を見て選ぶ → 盤上に行き先の破線と予測 → 確定
- 閻魔獄卒棒: 使う式神を選ぶ → 隣の選べる敵が光る → 選ぶと予測 → 確定
- 反撃の順番: 反撃する側に「反撃の順番」(上から順に反撃。▲▼か、盤上の駒を順にタップ。既定は盤上の並び順。その順番での結果の1行。「この順番で確定」)。攻撃した側には「相手が反撃の順番を選んでいます…」。AIの席はAIの評価で選ぶ
