## 1. 新規に実装するルール

すべて Config フラグ化し、**既定値では現行挙動と完全一致**させること(既存107テストが無改変で通る)。

### 1.1 撃破時の霊力: 撃破した側が得る(`refundMode: "killer_half"`)

既存の `refundMode` に値 `"killer_half"` を追加。

- 式神が撃破されたとき、**撃破した側のプレイヤー**が、撃破された式神の `floor(summonCost / 2)` 霊力を得る
- **撃破された側は霊力を得ない**
- 生命価の減少は従来どおり(撃破された側が失う)
- 「撃破した側」の定義: その撃破を引き起こした攻撃/効果の使用者。**AoEの味方巻き込みで自分の式神を倒した場合は、自分が自分の式神分を得る**(使用者=撃破者)。反撃で攻撃者が倒れた場合は、反撃した側が得る。閻魔獄卒棒など霊具のダメージは霊具使用者が得る
- 自滅(首引の姫鬼の【渾身】の自傷、古箪笥のHP消費など)で倒れた場合: **誰も得ない**(撃破者がいない)。裁定として報告に記載

### 1.2 継承召喚(`inheritSummon: boolean`、既定 false)

自分の式神がいるマスに、その式神を取り除いて新たな式神を召喚できる。

**条件**
- 新しい式神の `summonCost` が元の式神より**厳密に高い**(同値不可)
- **同属性のみ**。ただし**どちらかが空属性(`none`)なら可**(空→陰陽、陰陽→空の両方向OK)
- 元の式神が受けているダメージ量を引き継いだ結果、新しい式神の**実効HPが0以下になるなら不可**

**引き継ぐもの**
- 位置
- **向き(変更できない)**
- **ダメージ量**(`damage` フィールドをそのまま移す)
- **行動済みかどうか**(`attackedThisTurn` / `rotatedThisTurn` をそのまま移す。攻撃済みの式神を継承したら、そのターンは攻撃できない)
- マヨヒガで隠されている式神は継承の対象にできない(命令・効果の対象外のため)

**支払いと回収**
- 新しい式神の召喚コストを**全額**支払う(太極マスなら太極の軽減は適用する)
- 元の式神の `ceil(summonCost / 2)` を霊力として回収する
- 元の式神は墓地へ。**撃破ではない**ので生命価の減少も撃破時霊力も発生しない

**裁定(本書で確定)**
- 継承召喚でも新しい式神の**召喚時効果は発動する**(雲外鏡の「正面の式神のHPで召喚」など)。雲外鏡が継承でHPを上書きした場合、引き継いだダメージは適用しない(上書き後のHPをそのまま現在HPとする)
- 継承召喚後、行動済みでなければ、攻撃コストを払って攻撃できる(召喚攻撃と同じ扱い)
- AIは継承召喚を通常の召喚と同列の候補として列挙する

### 1.3 反撃の隙位置(`counterMode: "gap"`)

既存の `counterMode` に値 `"gap"` を追加。

反撃は次の**2条件がともに成立したときだけ**起きる:

1. 反撃する式神が、**攻撃側の隙位置**にいる
2. 反撃する式神の**反撃範囲**が、攻撃者のマスを含む

隙位置の定義:
- **単体攻撃**: 攻撃範囲**全体**が隙位置(つまり対象は必ず隙位置にいる。実質的に条件2だけを見ればよい)
- **範囲攻撃**: カードの `gapCell`(相対座標1マス)だけが隙位置。**`gapCell` が未定義の範囲攻撃は反撃を一切受けない**

その他:
- 反撃は**攻撃者への単体処理**。複数の反撃は発生しない(範囲攻撃でも隙位置の1体のみ)
- **味方からの反撃は発生しない**(既存どおり)
- **術式(`attackType: "jutsu"`)の攻撃は反撃を受けない。術式の式神は反撃もしない**
- 死角からの物理攻撃は反撃を受けない(既存どおり)
- 攻撃で撃破された式神は反撃しない(既存どおり)
- 反撃ダメージは反撃する式神の素のATK(既存どおり)

### 1.4 マリガン(`mulligan: boolean`、既定 false)

先攻の1ターン目開始前に、両者が1回だけ行う。

1. 手札5枚から残す札を選ぶ
2. 残さなかった札をデッキに戻してシャッフル
3. 戻した枚数と同じ枚数を引く

AIの判断則(固定): **召喚コスト5以上の式神を戻す**。霊具と召喚コスト4以下の式神は残す。

### 1.5 制圧状態の判定を変更(`controlHold: "next_turn_end"`)

新フラグ `controlHold: "next_turn_start" | "next_turn_end"`、既定 `"next_turn_start"`(=現行R2)。

`"next_turn_end"` のとき:
- **自分のターン終了時**に占拠が5マス以上 → 「制圧状態」になる
- 制圧状態は、**占拠が5マス未満になった瞬間に失われる**(相手のターン中でも、**自分のターン中でも**。例えば自分の範囲攻撃の味方巻き込みで5マスを割っても失う)
- **制圧状態を保ったまま、次の自分のターン終了時を迎えたら勝利**
- 判定順: ターン終了時効果 → **制圧判定(勝利判定 → 制圧状態の付与)** → 霊力獲得・手札整理

占拠数の再計算は、攻撃解決・霊具解決・召喚・継承のたびに行い、5未満なら即座に制圧状態を外す。

### 1.6 手札補充のモード(`handRefill` の解釈を2通り)

新フラグ `handMode: "refill_to_5" | "replace_discarded"`、既定 `"refill_to_5"`(=現行)。

- `refill_to_5`: ターン終了時、任意枚数捨てたあと**5枚になるまで引く**(現行・8/28ルール)
- `replace_discarded`: ターン終了時、任意枚数捨てたあと**捨てた枚数と同じ枚数だけ引く**(9/9改訂の文面どおり。プレイした分は補充されない)

**チームの文書に矛盾があり、どちらが意図か未確認**。両方測る。

AIの捨て札則は既存の固定則を流用する。`replace_discarded` の場合も同じ則で「捨てたい札」を選ぶ(手札が枯れる方向の圧力は、そのままモードの帰結として観測する)。

### 2.1 相対座標の変換規則(元データはテンキー記法)

元データは「5=自分のマス、向いている方向が2」のテンキー記法。本エンジンの相対座標(前=+y)への変換:

| トークン | 座標 | トークン | 座標 |
|---|---|---|---|
| `1` | (-1,+1) | `-1` | (-1,+2) |
| `2` | (0,+1) | `-2` | (0,+2) |
| `3` | (+1,+1) | `-3` | (+1,+2) |
| `4` | (-1,0) | `6` | (+1,0) |
| `7` | (-1,-1) | `8` | (0,-1) |
| `9` | (+1,-1) | | |

元データの文字列は**トークンの連結**(`-1-2-32` = `-1`,`-2`,`-3`,`2`、`-223` = `-2`,`2`,`3`、`1234` = `1`,`2`,`3`,`4`)。**このトークナイザを `cards.ts` 側に実装し、JSONには元の文字列を残したうえで座標を生成**すること(人手変換の誤りを防ぐため)。受け入れテストで下の検算例を必ず通すこと:

- `-1-2-32` → `[(-1,2),(0,2),(1,2),(0,1)]`
- `-223` → `[(0,2),(0,1),(1,1)]`
- `1234` → `[(-1,1),(0,1),(1,1),(-1,0)]`
- `138` → `[(-1,1),(1,1),(0,-1)]`
- `789` → `[(-1,-1),(0,-1),(1,-1)]`

`5x5ALL` は特殊: **向きに関係なく、盤面9マスのうち自分以外の全8マス**(絶対座標)。
