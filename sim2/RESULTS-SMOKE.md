# sim2 P3 スモーク結果

Date: 2026-08-30
実行: `node --experimental-strip-types sim2/src/cli.ts selfplay`
共通条件: `--games 50 --seed 20260830 --round-limit 40`(seed は 20260830..20260879 の連番)
主対象: `pack-tsukumo-miyako`(付喪神+京鬼)のミラーマッチ

数値の考察・解釈は書かない(設計側で引き取る)。以下は実行結果の事実のみ。

---

## 0. 既知バイアス(必読)

1. **カード効果は全て未実装。** 実デッキは効果が濃く、特に付喪神は効果依存が強い。本結果はカードのスタッツ・範囲・死角・属性のみで回した数値
2. **霊具(reigu)がデッキの約1/4を占める死に札。** tsukumo-miyako は 22枚中5枚、kyubi-ryu は 22枚中6枚。召喚不可で、手札整理時に優先的に捨てられるだけ。手札・墓地循環を歪めている
3. したがって数値は「**ルール層の傾向**」としてのみ読むこと。カードバランスの測定ではない
4. AIは greedy/beam とも本シム独自の近似。人間のプレイとは別物
5. 追加バイアス: `tm01 灯籠の精` `tm07 古箪笥` は atk=0 のため攻撃アクションを一切生成しない(効果未実装のため、実質は壁のみ)

## 3. 再現コマンド

```bash
for pack in tsukumo-miyako placeholder22; do
  for ai in greedy beam; do
    for cm in catch_up one_per_turn; do
      node --experimental-strip-types sim2/src/cli.ts selfplay \
        --games 50 --seed 20260830 --pack "$pack" --ai "$ai,$ai" \
        --chip-mode "$cm" --label "$pack/$ai/$cm" \
        --out "sim2/out/smoke-$pack-$ai-$cm.json" \
        --games-out "sim2/out/smoke-$pack-$ai-$cm.jsonl"
    done
  done
done
```

生成物は `sim2/out/`(gitignore)。`*.json` が集計、`*.jsonl` が1行1試合の生ログ。
