## 0. 実装状況

tsukumo-miyako の**効果ありカード16枚 + 霊具5枚を実装**。効果なしと明記された tm05/tm08/tm13/tm14 は対象外。

### 実装しなかったもの(死文)

**tm04 小鬼「この式神の回転命令に必要な霊力は0」— 実装せず。**
2026-08-28改訂⑪で回転コストが全カード一律1に統一され、個体差(小鬼0 / 一目鬼2)が撤廃されたため、
このテキストは参照先を失っている。`src/effects.ts` の冒頭にも同じ註記を置いた。

### 効果 off の回帰担保

`--effects off` は効果導入前の挙動と完全一致する。**効果導入前から存在する56テストが全て無改変で通過**
(`Unit` に新フィールドが増えたためテストヘルパの初期化のみ追随)。
`defaultConfig()` は `effects: false` を既定とし、旧挙動をピン留めしている。
CLI(`--effects`)と対戦UIはいずれも既定 on。

## 5. 実装の裁定(仕様どおり実装したもの)

| 項目 | 実装 |
|---|---|
| tm07 の選択 | AI・測定時は常に「HP-1 → 霊力+1」(仕様の固定則)。現HP2以上のときのみ発動(自壊しない)。**対戦UIの人間側のみ**「霊力+1 / 1ドロー / 使わない」を都度選択(F1〜F4の数値は固定則で取得) |
| tm09 渾身 | 通常攻撃と渾身攻撃を**別アクションとして列挙**。AIが選択可能 |
| tm10 巨撃 | 現在実効HP同士を比較 |
| tm11 雲外鏡 | 向き確定後の正面の現在実効HPを写す(1〜10でクランプ) |
| tm12 照魔鏡 | 攻撃解決時に動的参照。ATK置換を先に解決し、その後に加算修正(仕様§3) |
| tm15 再生 | 召喚攻撃では発動しない。`Unit.summonedThisTurn` で判定 |
| tm19 マヨヒガ | 占拠・リーチ・チップ・盤上HP合計から除外、攻撃/AoE/霊具の対象外、コマンド不可。**マスは塞いだまま** |
| tm21 鬼の酒 | 実効最大を超えて現HP7に固定。以後の回復で7未満へ引き下げない |
| tm22 閻魔獄卒棒 | 攻撃ではないため反撃・死角の対象外。正面が空/盤外なら使用不可 |
| ダメージ修正の累積 | 死角+2・影鬼+1・提灯+1・巨撃+1・渾身+1 はすべて加算 |

## 6. 再現コマンド

```bash
run() { # $1=ai $2=on|off $3=games $4=label
  node --experimental-strip-types sim2/src/cli.ts selfplay \
    --games "$3" --seed 20260830 --pack tsukumo-miyako --chip-mode catch_up \
    --ai "$1,$1" --effects "$2" --label "$4" \
    --out "sim2/out/eff-$4.json" --games-out "sim2/out/eff-$4.jsonl"
}
run greedy off 100 F1
run greedy on  100 F2
run beam   off  50 F3
run beam   on   50 F4
```

## 7. 既知バイアス

1. AI(greedy/beam)は霊具・バリアントを**1手先の評価値のみ**で選ぶ。人間の使い方とは別物
2. 評価関数は効果を明示的に評価していない(効果は盤面の結果としてのみ評価に入る)
3. 霊具はデッキ22枚中5枚。手札整理の既定則は、効果 off では霊具を死に札として優先廃棄し、
   効果 on では通常カードと同じく「次収入込みでも払えないもの」だけを捨てる
4. 手札整理はAIの判断ではなく `turn.ts` の固定則(人間はUIで自分で選ぶ)
5. カードのスタッツ・範囲・死角は設計側から受領した値をそのまま使用
